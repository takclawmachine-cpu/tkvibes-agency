# Phase 4: Hermes Operations Dashboard Implementation Plan

> **Goal:** Build a professional local CRM & Operations Dashboard for TKVibes Agency

**Architecture:** Next.js App Router + Prisma + SQLite + TailwindCSS v4. Dark-mode-first, desktop-first, responsive. Auto-refresh via polling.

**Stack:** Next.js 16.2.10, React 19, TypeScript 5, TailwindCSS v4, Prisma ORM, SQLite, Recharts (charts), react-beautiful-dnd (Kanban), lucide-react (icons)

---

## Phase 1: Foundation

### Task 1.1: Install dependencies
- Install: prisma, @prisma/client, recharts, lucide-react, @hello-pangea/dnd (maintained fork of react-beautiful-dnd), date-fns, clsx
- Init Prisma with SQLite

### Task 1.2: Create Prisma schema
- Tables: Business, Contact, Communication, Email, Task, Project, GeneratedAsset, Proposal, Meeting, Note, Tag, BusinessTag, AgentStatus, SkillStatus, TimelineEvent, ActivityLog, User, Backup
- Full relations and indexes

### Task 1.3: Create Prisma client singleton
- `src/lib/prisma.ts` - single instance

### Task 1.4: Create base layout + sidebar
- `src/app/layout.tsx` - dark theme root layout
- `src/app/globals.css` - TailwindCSS v4 styles
- Sidebar with all nav items

### Task 1.5: Create API routes
- CRUD for all entities
- Stats aggregation endpoint
- Search endpoint
