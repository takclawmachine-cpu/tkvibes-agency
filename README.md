# TKVibes Agency — Website

The marketing website for [TKVibes](https://tkvibes.in) — a boutique digital agency for modern service brands.

## Structure

```
├── index.html          # Home page
├── about.html          # About page
├── services.html       # Services page
├── packages.html       # Packages & pricing
├── portfolio.html      # Portfolio showcase
├── contact.html        # Contact form
├── 404.html            # 404 page
├── cold-call-training.html  # Free resource
├── send-plan-request.php    # Form handler
├── .htaccess           # Server config
├── robots.txt          # SEO
├── assets/
│   ├── css/styles.css  # All styles
│   └── js/             # JS modules
├── websites/screenshots/  # Portfolio images
├── favicon.ico
├── icon.png
├── apple-icon.png
├── tk-vibes-mark.svg
├── tk-vibes-logo.svg
└── TK-VIBES_LOGO.png
```

## Deployment

Deploy by FTP (Hostinger) — push entire repo contents to server root.

## Backend Systems

Backend infrastructure (CRM, lead engine, marketing engine, tools, scripts) lives in the separate **[tkVibes-Backend](https://github.com/takclawmachine-cpu/tkVibes-Backend)** repo.
